# Asrtl
Astrl (Astral) is a locally run personal AI assistant using Ollama.

This project is licensed under the MIT License - see the [LICENSE](LICENSE) file for details.

# About the model
Astrl currently uses the [qwen3:b](https://ollama.com/library/qwen3:8b) model. It was chosen for its performance on lower end systems but the model is subject to change. 

qwen3:8b has 8.19 billion parameters. It was last updated approximately around December of 2025. It is licensed under the Apache License 2.0.
